# MnaLauncher — native Android prototype

Полный самостоятельный проект, пересобранный по коду из переписки. Это не бинарно идентичный старый архив. Без WebView, HTML, JavaScript и внешних библиотек UI. Название: MnaLauncher. applicationId: com.mnalauncher.app (другой пакет, чем у старого Beige-проекта).

## Сборка на GitHub
1. Распакуйте ZIP, загрузите содержимое в КОРЕНЬ репозитория, включая скрытую папку .github. Не загружайте один ZIP.
2. Actions → Build MnaLauncher APK → Run workflow.
3. После успешного завершения скачайте Artifacts → MnaLauncher-debug.
4. Распакуйте MnaLauncher-debug.apk, установите на Android 8+.
5. Сначала протестируйте обычный запуск. Затем Настройки → Сделать главным экраном. Старый лаунчер не удаляйте.

JDK 17, AGP 8.7.3, Gradle 8.9, compile/target SDK 35. Workflow сам устанавливает Gradle; wrapper JAR не включён. Локальная сборка: с установленными JDK/SDK/Gradle и ANDROID_HOME выполните gradle :app:assembleDebug.
Это debug-подпись. Для постоянных обновлений настройте собственный постоянный ключ; CI debug-ключ может меняться. Приватные ключи не коммитьте.

## Что включено
- Нативный HOME launcher на Java / Android Views.
- Реальные иконки и запуск приложений личного профиля через LauncherApps.
- Тёмные панели, акцент, нижний док, анимированное переключение разделов.
- Часы и дата закреплены, не являются виджетом.
- Свободное перемещение и размер объектов в области под часами, сохранение настроек.
- Настоящие Android-виджеты через AppWidgetHost с разрешением и настройкой провайдера.
- Картинки-виджеты, заметки, поиск через браузер, локальные обои из переписки.
- Ваш бежевый Юпитер без надписи: legacy PNG и adaptive icon.

## Управление
Удерживайте приложение в списке для добавления на стол. Удерживайте ярлык на столе для включения редактирования, затем перетаскивайте. Либо включите редактирование в кастомизации. Правый нижний угол или кнопки − / ＋ меняют размер. ✓ завершает редактирование. Удаление ярлыка не удаляет программу.

## Ограничения и проверка
Компиляция Android, эмулятор и устройство здесь не запускались. Архив проверен на целостность и структуру, не на работоспособность APK. Первая GitHub Actions сборка — проверка компиляции. Прототип требует тестирования на реальном телефоне.
Интерфейс повторяет композицию веб-версии, но не пиксель в пиксель. Иконки приложений настоящие; док пока с текстовыми символами. Поддерживается личный профиль, не рабочие профили. Нет папок, нескольких страниц, Quickstep, жестового управления Recents. Провайдеры виджетов могут иметь ограничения размера; не все OEM-сценарии проверены. Слишком большие фото могут расходовать много памяти.
Запуск приложения запрашивает scale-up эффект у системы. Универсальное сворачивание окна стороннего приложения обратно в иконку НЕ реализовано: при возврате анимируется сам значок. Система может заменить анимацию запуска.
Права на загруженные пользователем изображения не передаются: для публикации проверьте разрешение на использование.
