# Beige Native Launcher — prototype

Нативный Android Java / Android Views проект. Нет WebView, HTML, JavaScript, CDN и веб-оболочки. Android 8.0+, compile/target SDK 35, AGP 8.7.3, Gradle 8.9, JDK 17. Полноценный базовый HOME launcher, но ранний прототип, не готовый production-продукт.

## Возможности
- Реальный список запускаемых Activity приложений текущего личного профиля, настоящие иконки, запуск через LauncherApps.
- Выбор главным экраном через системный RoleManager / настройки.
- Серо-чёрная тема, бежевый акцент, анимированная подложка дока и переходы разделов.
- Неперемещаемые часы и дата сверху рабочего стола.
- Свободное размещение ярлыков, масштабирование, сохранение JSON в SharedPreferences.
- Фото-виджет, заметка, поиск в браузере; выбор и копирование фото в приватную папку приложения.
- Реальные Android AppWidget: выбор провайдера, запрос разрешения привязки, конфигурация, AppWidgetHostView, удаление ID.
- Локальные обои из пользовательского изображения, изменение акцента, затемнения и скруглений.

## Управление
В списке приложений удерживайте значок для добавления на стол. Для перемещения включите режим в Кастомизации или удерживайте ярлык. Затем перетаскивайте; нижний правый угол меняет размер. Кнопки − и ＋ тоже масштабируют выбранный объект. Удаление ярлыка НЕ удаляет приложение. Для взаимодействия с виджетом выключите редактирование кнопкой ✓. Картинки и заметки перетаскиваются в режиме редактирования.

## Сборка в GitHub
Распакуйте ZIP и загрузите содержимое В КОРЕНЬ отдельного репозитория, включая скрытую папку .github. Не загружайте только ZIP. Actions → Build Native APK → Run workflow. После успеха скачайте Artifacts → BeigeNativeLauncher-debug, извлеките APK. Это debug APK, не подписанный вашим постоянным release-ключом. CI debug-ключ между запусками может меняться; для постоянных обновлений настройте свой ключ. Секретные ключи не коммитьте.
Сборка локально: установите JDK 17, SDK 35, Gradle 8.9, задайте ANDROID_HOME и выполните `gradle :app:assembleDebug`. Wrapper JAR не включён; workflow устанавливает Gradle напрямую.

## Проверка и ограничения
Android-компиляция, эмулятор и устройство в среде подготовки не запускались. Первая CI-сборка проверяет компилируемость. Перед выбором HOME протестируйте запуск, поиск, возврат домой, перемещение и виджеты на своём устройстве. Старый лаунчер не удаляйте. Вернуться можно в системных настройках главного экрана.

Интерфейс перенесён на native Views, а не идентичен HTML пиксель в пиксель. Иконки приложений — настоящие системные, не Remix. Значки дока пока текстовые символы. Поддержка личного профиля; рабочие профили, App Shortcuts, папки, несколько страниц, масштабные accessibility-тесты, обработка всех OEM-особенностей и жестовая Quickstep-интеграция пока отсутствуют. Обновление списка — при возврате в Activity. Положение объектов ограничено областью под часами. Изображения не подвергаются предварительному downsampling: очень большие фото могут потреблять много памяти.

Анимация запуска запрашивается через ActivityOptions.makeScaleUpAnimation. Android/OEM могут её заменить. Универсальная анимация сворачивания чужой Activity «в иконку» не реализована: обычный сторонний HOME не получает тот же контроль, что привилегированный системный Quickstep. При возврате анимируется сам значок, не окно чужого приложения. Не обещаем точного системного поведения.

Привязка виджетов требует согласия пользователя. Если настройки провайдера отменены, ID удаляется. Редкие сценарии убийства процесса во время внешней конфигурации требуют дополнительного тестирования; после такого сбоя используйте сброс/перезапуск. Для виджетов соблюдаются минимально разумные размеры, но не все ограничения отдельных провайдеров.

## Структура
MainActivity.java — нативный UI, приложения, настройки, сохранение, AppWidgetHost.
app/src/main/assets/wallpaper.jpg — присланные пользователем обои, если они были доступны при упаковке. Права на изображение не передаются: для публичного распространения проверьте право использования или замените его.
